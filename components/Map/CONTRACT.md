# MapMarker / PlaceCarousel / Category 계약

- 구현: ../../map-live.js `favoriteButton()`, `searchPlaces()`, 마커·캐러셀 렌더링; ../../map-refresh.css와 ../../ui-unify.css. 공통 보정은 ../../design-alignment.css.
- 캐러셀: 장소 목록과 선택 장소, 저장 여부/favorite, 제목·주소·사진. 번호·점·X 없음. 왼쪽 사진 정사각형, 오른쪽 제목+하트, 아래 저장 시점+주소+상세 화살표.
- 지도 별은 좌표가 확인된 저장 장소에 표시하고 장소별 favorite 값을 토글한다. 상세의 추출 장소는 위치 확인 전에도 각 행에서 즐겨찾기할 수 있으며, 지도에 핀이나 사진을 임의로 만들지 않는다. 게시물 상세 상단의 별은 게시물 favorite 값을 토글하며 장소 즐겨찾기를 바꾸지 않는다. 공통 `paths.star`의 뾰족한 별 20×20px을 기본 윤곽·선택 채움으로 사용하고 기존 색을 유지한다. 캐러셀·목록은 투명한 44×44px 터치 영역을 유지하고, 게시물 상세 상단 별은 원래의 반투명 원형 버튼 배경을 사용한다. 지도·상세·컬렉션 별을 켜면 윤곽이 채움으로 전환되고 별이 350ms 팝하며 작은 입자 8개가 퍼진다. 끌 때는 240ms 안에 작아졌다 돌아온다. 움직임 줄이기 설정에서는 효과를 생략한다. 같은 콘텐츠에 여러 장소가 있어도 각 별은 독립적이다. 마이 즐겨찾기 목록은 게시물과 장소를 나눠 보여준다.
- 상단 카테고리와 사진의 서브 뱃지는 같은 SVG 원본. 비선택 secondary 윤곽, 선택 primary 면 채움. 전체 별은 원래 채움 유지. 기존 분류 키를 유지한다.
- 사진 원은 선택 시 360ms, scale(1.4), translateY(-10px). DOM/앵커 교체 금지. reduced-motion에서는 전환 제거.
- 검색·위치 제목은 같은 행에 둔다. 지도 위의 직접 핀 추가와 새 코스 원형 버튼은 표시하지 않고, 현재 위치 버튼은 유지한다. 검색 아이콘은 24px이며 버튼 영역과 아이콘 크기는 별개다.
- 지도 검색은 우측 같은 44×44px 버튼에서 돋보기와 닫기 X가 전환된다. 필드는 그 버튼 뒤에서 왼쪽으로 펼쳐지고, 입력 후 키보드의 검색 키로 제출한다. 모션 축소 설정에서는 전환 애니메이션을 생략한다.
- 검색 중 카테고리 줄은 숨기고 검색 결과를 필드와 같은 폭의 둥근 카드로 8px 아래에 배치한다. 장소 목록이 열려 있으면 검색을 열 때 닫아 X가 겹치지 않게 한다. 우상단 X만 검색 닫기에 사용한다.
- 검색을 열고 닫아 상단 헤더의 높이가 바뀌면 Google 지도 배경의 시작 위치도 즉시 맞춘다. 이전 헤더 높이만큼 회색 빈 띠가 남지 않게 한다.
- 검색 결과의 단위는 좌표가 있는 개별 저장 장소다. 한 글자부터 입력 즉시 갱신하고 현재 지도 중심에 가까운 결과를 우선한다. 장소명·주소·지역·분류 결과를 게시물 제목·요약 결과보다 먼저 보여주며, 선택한 장소의 핀·카드·상세 위치가 일치해야 한다. 외부 장소는 검색 결과에 섞지 않는다.
- 캐러셀과 하단 내비 사이에는 출처 링크 줄을 표시하지 않는다. 지도 안의 44×44px 정보 버튼에는 현재 보이는 네이버 또는 구글 지도 출처를 표시한다.
- 지도 탭은 국내 위치에서 네이버 지도를 기본 배경으로 사용한다. 지도 탭에서 장소 선택·검색·필터·지도 이동은 배경 제공자를 바꾸지 않고, 오른쪽 전환 버튼을 누를 때만 네이버·구글 지도를 바꾼다. 화면이 다시 그려져도 사용자가 선택한 제공자를 유지한다. 지도 탭을 해외 위치에서 처음 열면 구글 지도로 시작할 수 있으며, 네이버 지도 연결에 실패한 경우 구글로 대체한다. 장소 상세·코스처럼 전환 버튼이 없는 지도는 해외 콘텐츠에 구글 지도를 자동 선택한다. 필요한 키 또는 인증이 없으면 연결 오류를 표시한다. 장소 마커·카드·위치·줌은 유지하고 지도 제공자 표기는 가리지 않는다.
- 지도 전환 버튼은 누르면 바뀔 제공자를 표시한다. 현재 네이버 지도에서는 Google 공식 컬러 G, 현재 구글 지도에서는 네이버 공식 N을 사용한다. 지도 앱 핀 아이콘이나 글꼴 N/G로 다시 그리지 않고, 원본 색과 비율을 유지한다.
- 지도 상단의 즐겨찾기 버튼은 표시할 장소만 좁힌다. 이 버튼 때문에 현재 네이버·구글 지도 배경이 바뀌지 않도록, 제공자 판단에는 즐겨찾기 적용 전의 현재 카테고리·검색 결과를 사용한다.
- 저장한 장소의 위도·경도는 두 배경에 같은 값으로 전달하며 지도 전환 시 변경하지 않는다. Google Places API에서만 얻은 장소 좌표는 네이버 지도 위에 표시하지 않는다. 해당 장소를 네이버 지도에서 선택하면 구글 지도 전환 버튼을 안내하고 지도 배경은 유지한다.
- 검증: 카테고리 전환 시 같은 도형, 마커와 카드 선택 연동, 하트 저장/해제, 정사각형 이미지, 긴 제목, 402px 및 넓은 미리보기, 실제 현재 위치·방향 권한 허용/거부와 위치 감시 해제.

정상 예: 기존 지도 DOM과 선택 상태를 재사용하며 토큰만 연결한다.
반례: 선택 때 다른 모양의 SVG로 교체하기; 지도 좌표 대신 화면 고정 위치에서 마커를 확대하기; 예시 위치를 GPS 결과라고 표시하기.

- 지도 상단 카테고리는 전체 포함 6개 이하면 같은 너비로 행 전체에 균등 분배하고 아이콘·이름을 각 칸 중앙에 놓는다. 7개 이상은 기존 6칸 너비와 가로 스크롤을 유지한다. 활성화 바는 44px 길이를 유지하고 선택한 실제 버튼의 중심에 맞춘다.
- 카테고리 바는 아이콘과 이름의 크기를 유지하면서 아래쪽 빈 공간을 줄인다. 활성화 바는 줄어든 흰 상단바의 맨 아래, 지도와 만나는 경계에 놓는다.

## 2026-11-25 사용자 지도 시안 적용

이 절은 위의 이전 상단바·사진 마커·캐러셀 규격보다 우선한다. 지도는 화면 전체에 놓고, 성수동을 서울 기본 화면으로 사용한다. 실제 현재 위치를 허용한 사용자는 기존 위치 추적을 유지한다. 국내에는 네이버, 해외에는 구글 지도 전환을 유지한다.

- 기준 프레임 402×874. 검색바 x17 y40 369×53, 프로필 사진 원 35×35. 필터 칩은 x17 y104부터 홈 카테고리 칩과 같은 글자·32px 높이로 표시하고 가로로 스크롤한다. `전체` 뒤에는 좌표가 있는 저장 장소가 실제로 속한 카테고리만 표시한다. 저장한 장소가 없으면 `전체`만 표시한다. 활성·비활성 글자는 같은 600 14px/20px이며 아이콘과 텍스트의 20px 상자 중심을 버튼 높이의 중심에 맞춘다. 칩 그림자는 이전 지도 값인 `0 0 20px rgba(0,0,0,.1)`을 사용하고 스크롤 영역에 상하·좌우 20px 여유를 둬 개별 그림자가 잘리지 않게 한다. 선택한 칩은 검은 배경·흰 글자와 기존 카테고리의 `-active-dark.svg` 채움형 아이콘 원본을 흰색으로 표시한다. 마스크로 원본 내부 선을 지우지 않는다. 홈 카테고리 칩도 같은 원본 아이콘·중앙 정렬·그림자를 공유한다.
- 지도 위 지도 전환·별·현위치 버튼은 오른쪽 x338, 각각 y338·384·430에 36×36. 장소 핀은 검은 원 안 카테고리 아이콘과 아래 장소 이름을 사용한다.
- 장소 핀의 카테고리 아이콘은 지도·홈 칩과 같은 `*-active-dark.svg` 채움형 원본을 사용하며 내부의 어두운 선을 보존한다. 하단 `근처 장소` 탭은 사용자가 제공한 Map Point Bold/Linear 경로를 선택·비선택 상태에 사용한다. Bold의 가운데 빈 원을 보존하고 두 상태 모두 기존 표시 크기 18px·기존 검정 `#282828`을 유지한다.
- 하단 패널은 x0 y491 402×383, 위 모서리 30px. 손잡이 x172 y502 57×5. 탭 배경 x17 y526 369×58, 활성 탭은 흰색 174×44, 선택 아이콘은 `#00FFD4`.
- 근처 장소 탭은 현재 지도 주변의 저장 장소를 91×91 사진, 이름·주소·설명, 독립된 즐겨찾기 별로 표시한다. 코스 탭은 저장한 코스를 369×174 카드와 158×150 실제 경로 미리보기로 표시한다. 빈 상태도 실제 저장 데이터에 따라 표시한다.
- 시안 색상은 흰색, `#282828`, `#2E2E2E`, `#F0F2F4`, `#858B95`, `#00FFD4`를 사용한다. 지도와 콘텐츠 데이터는 고정 이미지로 바꾸지 않는다. 기존 공통 하단 내비게이션을 별도로 다시 그리지 않고 지도 대표 화면에도 같은 인스턴스를 표시한다. 목록 끝은 내비게이션 뒤에 가려지지 않게 스크롤 여백을 둔다.

## 2026-11-26 지도 목록과 뱃지 동작

- 검색바의 프로필 이미지·기본 사람 아이콘을 35×35 원의 중앙에 둔다. 근처 장소 탭의 선택 아이콘은 기존 검정 `#282828`으로 표시한다.
- 근처 장소 행에서 사진·이름·설명을 누르면 해당 장소 뱃지가 보이는 지도 위치로 이동한다. 주소만 상세 페이지를 열고, 즐겨찾기 별은 기존 기능을 유지한다.
- Google Places API에서만 얻은 장소는 구글 지도에서만 뱃지로 표시한다. 다른 국내 장소의 뱃지는 네이버 지도 위에 표시한다. 지도 안에서 장소를 선택할 때는 배경을 바꾸지 않는다.
- 게시물 상세의 좌표가 확인된 장소는 68px 지도 미리보기 버튼 가운데에 지도와 같은 원형 카테고리 마커를 표시한다. 미리보기는 해당 장소 좌표에 고정하며 드래그나 확대를 받지 않는다. 버튼을 누르면 지도 탭을 열고 해당 장소 핀을 선택한다. 해외 또는 Google Places 전용 장소는 구글 지도로 열고, 좌표가 없는 장소에는 지도 버튼을 표시하지 않는다.

## 2026-11-26 코스 미리보기 사진

- 지도 페이지 코스 카드의 작은 지도만 흑백으로 표시한다. 경로선과 방문 지점은 검정색으로 유지하고, 각 지점 옆에는 해당 저장 장소의 대표 사진을 컬러 정사각형으로 표시한다.
- 장소별 사진이 있으면 그 사진을 사용하고, 없으면 해당 게시물의 대표 사진을 사용한다. 둘 다 없는 경우에만 기존 사진 없음 이미지를 사용한다. 사진은 지도 타일의 흑백 필터 바깥에 두어 색이 변하지 않게 한다.
- 코스 상세 지도와 다른 화면의 사진 핀은 기존 표시를 유지한다.

## 2026-11-26 지도 아이콘과 전환

- 지도 검색·프로필 기본 아이콘·지도 조작·장소 별·코스 장소 아이콘은 같은 18~20px 범위로 맞춘다. 홈과 공유하는 카테고리 아이콘 20px, 사용자 요청으로 복원한 근처 장소 탭 아이콘 18px, 공통 하단 내비게이션은 유지한다.
- 지도 상단 즐겨찾기 필터와 장소 행의 별은 원래 지도의 뾰족한 `paths.star` 경로를 사용한다. 공통 `likeHeartIcon()`이 이 경로를 윤곽·채움 상태에 사용하므로 다른 화면의 별도 동일하다.
- 근처 장소와 코스 탭 전환은 선택 배경과 두 목록의 수평 이동·흐림 전환을 250ms로 표시한다. 비활성 목록은 포커스와 접근성 탐색에서 제외한다. 움직임 줄이기 설정에서는 전환 없이 상태만 바꾼다.
- 지도 목록의 전환 상태는 `data-map-panel`에 둔다. `data-page`는 앱 전체 화면 이동에 예약되어 있으므로 목록이나 별 버튼의 상위 요소에 사용하지 않는다.
- 저장 장소 핀은 현재 지도 화면에서 42px 이내의 위치가 겹칠 때 묶는다. 2곳 이상은 34px 원 안에 `+2`처럼 개수를 표시한다. 지도를 확대·이동할 때마다 다시 묶고, 묶음을 누르면 확대한다. 목록에서 선택한 장소 핀은 단독으로 표시한다.
