# MapMarker / PlaceCarousel / Category 계약

- 구현: ../../map-live.js `favoriteButton()`, `searchPlaces()`, 마커·캐러셀 렌더링; ../../map-refresh.css와 ../../ui-unify.css. 공통 보정은 ../../design-alignment.css.
- 캐러셀: 장소 목록과 선택 장소, 저장 여부/favorite, 제목·주소·사진. 번호·점·X 없음. 왼쪽 사진 정사각형, 오른쪽 제목+하트, 아래 저장 시점+주소+상세 화살표.
- 지도 하트는 좌표가 확인된 저장 장소에 표시하고 장소별 favorite 값을 토글한다. 상세의 추출 장소는 위치 확인 전에도 각 행에서 좋아요할 수 있으며, 지도에 핀이나 사진을 임의로 만들지 않는다. 게시물 상세 상단의 하트는 게시물 favorite 값을 토글하며 장소 좋아요를 바꾸지 않는다. Bencho Like의 Lucide 하트 20×20px·2px 선·#e5484d 선택색을 사용한다. 숫자는 제외한다. 캐러셀·목록은 투명한 44×44px 터치 영역을 유지하고, 게시물 상세 상단 하트는 원래의 반투명 원형 버튼 배경을 사용한다. 캐러셀 하트와 게시물 상세 상단 하트는 같은 Bloom 링·일곱 쌍의 입자·0.76초 탄성 복귀를 재생하고, 해제 및 움직임 감소 설정에서는 효과를 생략한다. 같은 콘텐츠에 여러 장소가 있어도 각 하트는 독립적이다. 마이 즐겨찾기 목록은 게시물과 장소를 나눠 보여준다.
- 상단 카테고리와 사진의 서브 뱃지는 같은 SVG 원본. 비선택 secondary 윤곽, 선택 primary 면 채움. 전체 별은 원래 채움 유지. 기존 분류 키를 유지한다.
- 사진 원은 선택 시 360ms, scale(1.4), translateY(-10px). DOM/앵커 교체 금지. reduced-motion에서는 전환 제거.
- 검색·위치 제목은 같은 행에 둔다. 지도 위의 직접 핀 추가와 새 코스 원형 버튼은 표시하지 않고, 현재 위치 버튼은 유지한다. 검색 아이콘은 24px이며 버튼 영역과 아이콘 크기는 별개다.
- 지도 검색은 우측 같은 44×44px 버튼에서 돋보기와 닫기 X가 전환된다. 필드는 그 버튼 뒤에서 왼쪽으로 펼쳐지고, 입력 후 키보드의 검색 키로 제출한다. 모션 축소 설정에서는 전환 애니메이션을 생략한다.
- 검색 결과의 단위는 좌표가 있는 개별 저장 장소다. 한 글자부터 입력 즉시 갱신하고 현재 지도 중심에 가까운 결과를 우선한다. 장소명·주소·지역·분류 결과를 게시물 제목·요약 결과보다 먼저 보여주며, 선택한 장소의 핀·카드·상세 위치가 일치해야 한다. 외부 장소는 검색 결과에 섞지 않는다.
- 캐러셀과 하단 내비 사이에는 출처 링크 줄을 표시하지 않는다. 지도 안의 44×44px 정보 버튼을 누르면 구글 지도 표기를 확인할 수 있다.
- 지도 탭·장소 상세·코스 화면은 스타일을 지정하지 않은 구글 지도 기본 배경을 사용한다. 구글 지도의 기본 도로·상점·지역명 표시를 따른다. 지도 제공자 선택 버튼이나 지도 디자인 메뉴는 두지 않는다. 키 또는 인증이 없으면 연결 오류를 표시한다. 장소 마커·카드·위치·줌은 유지하고 구글 지도 표기는 가리지 않는다.
- 검증: 카테고리 전환 시 같은 도형, 마커와 카드 선택 연동, 하트 저장/해제, 정사각형 이미지, 긴 제목, 402px 및 넓은 미리보기, 실제 현재 위치·방향 권한 허용/거부와 위치 감시 해제.

정상 예: 기존 지도 DOM과 선택 상태를 재사용하며 토큰만 연결한다.
반례: 선택 때 다른 모양의 SVG로 교체하기; 지도 좌표 대신 화면 고정 위치에서 마커를 확대하기; 예시 위치를 GPS 결과라고 표시하기.
