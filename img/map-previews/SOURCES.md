# 지도 디자인 썸네일 출처

2026-11-14 각 제공자의 실제 서울숲 지도 화면을 브라우저에서 캡처했다. 생성 이미지나 공통 예시 도형을 사용하지 않는다. 선택 카드에 제공자 출처를 표시한다. 이미지 소유권은 각 지도 제공자/데이터 권리자에게 있다.

- naver-seoul-forest.png: NAVER 지도, https://map.naver.com/p/search/%EC%84%9C%EC%9A%B8%EC%88%B2?c=15.00,0,0,0,dh
- kakao-seoul-forest.png: Kakao 지도, https://map.kakao.com/?q=%EC%84%9C%EC%9A%B8%EC%88%B2
- google-seoul-forest.png: Google Maps / TMap Mobility 지도 데이터, https://www.google.com/maps/@37.5445,127.043,16z?hl=ko

360×360 PNG로 캡처했으며 UI에서는 기존 80×80 썸네일 크기로 표시한다. 실제 지도 화면의 일부이며 지도 종류 선택용 정적 미리보기다. 설정 화면 방문 때 지도 API를 추가 호출하지 않는다.
