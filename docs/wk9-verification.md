## 검증과 남은 범위

- 자동 검사: 34개 통과. 기존31개 + 비동기 버튼2개 + 토큰 수/모드 역할/대비/문서 값 일치1개.
- 검색 아이콘: 접힘/펼침 모두24×24, 중심(356,50)으로 일치. 검색 UI가 헤더 아래로 새 행을 만들지 않는다.
- 지도 검색: “성수” 검색으로 저장 장소4곳 반환. 외부 검색 API의 정확도·지속 가용성은 이번 작업에서 평가하지 않았다.
- 실제 Dark 화면 전체 전환, 모든 사진/유리 배경의 합성 대비, 모든 하위 화면의 모든 상태 조합은 검증 전이다. Dark 토큰 정의와 단색 대비 검사는 통과했다.
- Figma: 현재 계정 Starter MCP 호출 한도로 페이지 읽기부터 차단되었다. Figma 서체/Variables/스타일 수정 완료로 표시하지 않는다.
- 독립 평가: 별도 새 대화창에서 실시해야 한다. 현재 보고서는 구현자 자체 검증이다.

- 화면 크기: 402×874 앱 프레임과 넓은 호스트 화면에서 홈·지도·저장함 캡처. 지도 document clientWidth/scrollWidth 모두402px, 가로 넘침 없음.
- 마커: 카페 선택→마커 클릭에서 0.36초 전환과 scale 약1.4 확인. 원래 선택/전체 보기로 테스트 상태 복구.
- 비교 캡처는 [로컬 결과 폴더](../../outputs/wk9-alignment-20261031/)에 있다. 적용 전 홈은 동일 기준 커밋을 별도 로컬 포트에서 실행해 튜토리얼을 닫은 후 다시 캡처했다. 프로토타입 사진 순서는 초기화 시 달라질 수 있으며 저장 날짜/콘텐츠 차이를 디자인 변경으로 해석하지 않는다.
