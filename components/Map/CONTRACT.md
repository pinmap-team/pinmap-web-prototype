# MapMarker / PlaceCarousel / Category 계약

- 구현: ../../map-live.js `favoriteButton()`, `searchPlaces()`, 마커·캐러셀 렌더링; ../../map-refresh.css와 ../../ui-unify.css. 공통 보정은 ../../design-alignment.css.
- 캐러셀: 장소 목록과 선택 장소, 저장 여부/favorite, 제목·주소·사진. 번호·점·X 없음. 왼쪽 사진 정사각형, 오른쪽 제목+하트, 아래 저장 시점+주소+상세 화살표.
- 하트는 저장 장소에만 표시하고 기존 favorite 값을 토글한다. 선택은 color-error와 aria-pressed로 표시한다. 하트와 상세 버튼은 각각 44×44px이며 영역이 겹치지 않는다.
- 상단 카테고리와 사진의 서브 뱃지는 같은 SVG 원본. 비선택 secondary 윤곽, 선택 primary 면 채움. 전체 별은 원래 채움 유지. 기존 분류 키를 유지한다.
- 사진 원은 선택 시 360ms, scale(1.4), translateY(-10px). DOM/앵커 교체 금지. reduced-motion에서는 전환 제거.
- 검색·위치 제목은 같은 행, 우측 코스/현위치 원 버튼 유지. 코스 아이콘18px, 검색 아이콘24px; 버튼 영역과 아이콘 크기는 별개.
- 검증: 카테고리 전환 시 같은 도형, 마커와 카드 선택 연동, 하트 저장/해제, 정사각형 이미지, 긴 제목, 402px 및 넓은 미리보기, 권한 없는 예시 위치 표시.

정상 예: 기존 지도 DOM과 선택 상태를 재사용하며 토큰만 연결한다.
반례: 선택 때 다른 모양의 SVG로 교체하기; 지도 좌표 대신 화면 고정 위치에서 마커를 확대하기; 예시 위치를 GPS 결과라고 표시하기.
