## 자동 검사 및 남은 범위

`node --test tests/*.test.cjs`: **40 통과 / 0 실패**. [실행 로그](../../outputs/wk9-interaction-20261031/automated-tests.txt). 이번에 추가한 회귀 검사는 상세 복귀 시 재생성된 올바른 카드로 포커스를 돌리는지, 검색 실패 안내가 숨겨지지 않는지 확인한다.

실제 GPS·방향 센서, 실제 휴대폰의 네이티브 키보드, 운영체제의 동작 줄이기 전환은 이 데스크톱 브라우저 검증에 포함하지 않았다. 데스크톱 화면 키보드와 물리 키 입력을 검증했다. 모션의 0.36s 정의와 확대 결과는 확인했지만 매 프레임의 성능이나 모든 기기를 보증하지 않는다. 기존 빨간 배지의 흰 글자 대비 예외 및 Figma와 코드의 차이는 이 조작 검증으로 해결되는 항목이 아니다.
